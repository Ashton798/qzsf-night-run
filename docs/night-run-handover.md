## 三、密钥填在哪

打开项目根目录 `.env`，找到这两行（在文件末尾附近）：

```ini
AMAP_WEB_KEY=你的Web端(JS API)Key
AMAP_SECURITY_JS_CODE=你的安全密钥
```

- 申请地址：高德开放平台 → 应用管理 → 创建应用 → 添加 Key → **服务平台选「Web端(JS API)」**
- 两项必须配套：只填 Key 不填安全码，JS API 2.0 会拒绝加载
- 改完 `.env` 必须**重启服务**才生效
- 安全密钥不会下发到浏览器：前端只拿到 Key 和 `/_AMapService` 代理路径

## 四、路线数据（本轮核心产出）

坐标基准统一 **GCJ-02**（与高德底图一致）。GPS 原始 WGS-84 在客户端保留 `raw`，服务端重新转换，客户端上报的坐标不被信任。

### A · 竞赛组 疾风红线

**3316 m / 65 个途经点 / 3 个盖章点**

荣茂楼正门口 → 千墅楼 → 音舞湖尾段（CP1）→ 上坡右转 → 理工篮球场 → 明德体育馆 → D区（CP2）→ C区 → 三餐 → 一餐 → 第一操场入口（CP3）→ 第一操场侧门（终点）

### B · 体验组 / 同心组 友情蓝线

**2557 m / 63 个途经点 / 3 个盖章点**

荣茂楼正门口 → 千墅楼 → 音舞湖尾段（CP1）→ 上坡往回 → 俊秀图书馆 → 陈祖昌大礼堂 → 钟楼（CP2）→ 孙中山纪念堂 → 文科楼 → 第一操场入口（CP3）→ 第一操场侧门（终点）

蓝线/红线 = 0.77，与策划书“蓝线约为红线一半”的表述同量级（策划书未给具体公里数）。

**方法说明与局限（务必如实告知主办方）**

1. 路线骨架来自 OpenStreetMap 的真实校园道路（WGS-84 已转 GCJ-02），叠加高德底图验证重合。
2. OSM 在 **C区 → 三餐** 和 **一餐 → 第一操场入口** 两段缺失道路，若纯用最短路会绕行 1.9 km / 1.7 km。这两段按高德底图上可见的道路手工补齐，GeoJSON 中标记 `inferred`。
3. 三个盖章点经计算均落在路线上（偏离 0.0 m），但**具体设点位置（哪棵树、哪个门口）必须现场定**。
4. 生成后做了一次「道路像素吸附」（`server/scripts/snap-routes.js`）：把 22 个明显切角的节点拉到高德底图白色道路中心线上；起终点与三个盖章点位置受保护、不移动。
5. 策划书的两张路线图是透视示意图，政府平面图无坐标控制点，**无法做地理配准**。因此没有“照着图描”这回事，只能按文字描述 + 真实道路还原。
6. 本路线为 **draft**。数据库里 `status='draft'`，选手端显示为虚线并提示“不能开跑”。

## 五、怎么测试

### 1. 启动服务

```bash
cd E:/学校定位小程序
node server/index.js
```

看到 `高德地图：已配置` 说明密钥读取成功。默认端口取 `.env` 的 `PORT`（本机测试用 8778）。

### 2. 选手端（手机优先，竖屏）

```
http://<你的局域网IP>:8778/?page=map
```

- 已报名：按报名组别自动加载对应路线
- 未报名踏勘：加 `?group=competition` / `?group=experience` / `?group=unity` 预览
- 站在荣茂楼门口应看到：红色（或蓝色）虚线路线 + 自己的蓝点 + 精度圈 + 起终点和 1/2/3 三个盖章点

### 3. 管理后台

```
http://<你的局域网IP>:8778/?page=night-admin
```

- 登录：`admin` / 见 `.env` 的 `ADMIN_PASSWORD`
- 「路线编辑」：可拖动任意节点微调，右侧可改打卡点坐标
- 「现场核对与发布」：填写核对人/日期/来源/逐段贴合确认后才会真正发布

### 4. 自动化测试

```bash
node server/scripts/amap-config-test.js   # 27 项：代理与配置安全
node server/scripts/night-test.js         # 29 项：业务规则（隔离临时库）
node server/scripts/acceptance.js         # 42 项：真实服务端到端
```

路线重新生成（改了锚点或补齐走廊后）：

```bash
python tools/make-road-mask.py            # 1. 提取道路掩膜
node server/scripts/build-night-routes.js # 2. 沿路网生成 + 补齐 + 去毛刺
node server/scripts/snap-routes.js        # 3. 吸附到道路中心线
node server/scripts/import-night-routes.js # 4. 写入数据库（draft）
```

## 七、规则要点（已固化进代码）

- **GPS 不能盖章**：`/api/runs/:id/hit` 要求管理员/裁判会话 + 游戏完成 + 备注；`methods` 只有 `manual`
- **单次漂移不判违规**：跳点只存证不入有效轨迹，异常交管理员审核
- **防抄近道**：已过路段只按相邻节点推进，不会把捷径涂绿
- **同心组**：一队一条报名记录，按共同场次计时；需两人同时在场（`bothPresent`）
- **发布门槛**：缺核对人/日期/来源/逐段确认/地标绑定节点，一律拒绝发布
